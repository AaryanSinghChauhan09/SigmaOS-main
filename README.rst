SigmaOS
-------

SigmaOS is an early-development, modular Rust operating-system project. The
workspace currently contains ten crates: ``sigma-adjustments``,
``sigma-bootloader``, ``sigma-display``, ``sigma-drivers``, ``sigma-kernel``,
``sigma-persona``, ``sigma-power``, ``sigma-system``, ``sigma-terminal``, and
``sigma-file-manager``.

The feature register snapshot dated 2026-11-05 lists 57 status entries:
32 Integrated, 14 Prototype, 10 Proposed, and 1 Supported. These are project
status labels, not independent validation. The register reports no verified
QEMU x86_64 boot and says installer, update, and hardware support still need
validation.

See the `SigmaOS component wiki <https://github.com/AaryanSinghChauhan09/SigmaOS/wiki/Component-SigmaOS-main-Guide>`_
for architecture, registry metadata, and documentation links. The feature
register is in ``feature-register.json``. The repository is licensed under
GPL-3.0-or-later.
